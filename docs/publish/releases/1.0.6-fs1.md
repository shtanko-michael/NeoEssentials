First public release of **Farmstead NeoEssentials**, based on NeoEssentials 1.0.6 (`1.21.x`).

It keeps the mod id `neoessentials` and replaces the original jar — remove the original before installing.

**On top of NeoEssentials 1.0.6**

- Complete Russian localization: every message, `/help` entry and command hint. English stays the default (`localization.language` in `config.json`).
- Staff chat, admin notices, a moderation chat log and a staff compass teleport.
- Tablist: per-player name colour from a LuckPerms meta key (`farmstead-namecolor`), rank colours in `/list`, a row anchored under another player's row.
- Player-name tab completion in every command that takes a player.
- `/repair all`; fly and god mode survive a relog; mobs ignore god-mode players.
- Configurable join and quit announcements.
- With the RegionGuard mod installed, `/home`, `/tpa` and `/back` refuse to land a player in a region that forbids teleporting in.
- Fixes: immediate TPA acceptance, jail durations, mute message line breaks, fly speed, stale nicknames after a rename, config-split data loss, vanilla `/help` hijacking `/help <page>`, command-name case handling, permission details leaking in denial messages.
- One shaded jar: HikariCP, SnakeYAML and Java-WebSocket are relocated and cannot clash with other mods.

**Requirements:** Minecraft 1.21.1, NeoForge 21.1.179+, Java 21. Server-side only.

Documentation: https://shtanko-michael.github.io/NeoEssentials/
