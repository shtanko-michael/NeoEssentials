Besides the big mods, the Farmstead server runs a few small ones. All of them go on the server only — **NeoForge 21.1.230+ / Minecraft 1.21.1** — and players install nothing.

| Mod | modId | What it does |
|---|---|---|
| [Farmstead Chunk Breeding Limit](chunk-breeding-limit/) | `farmstead_chunkbreeding` | Caps the number of animals in a chunk or in a [Farmstead Claims](../claims/) region: no new baby appears once the cap is reached. Existing animals are never removed |
| [Farmstead Trade Chat](trade-chat/) | `farmstead_tradechat` | A trade channel: a message starting with `@` goes to every player with the channel tag (`[Торговля]` by default) |

The source code of both mods lives in the [Farmstead monorepo](https://github.com/shtanko-michael/minecraft-api/tree/main/game).
