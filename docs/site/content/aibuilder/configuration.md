Файл `config/farmstead_aibuilder.toml` создаётся при первом запуске сервера. Комментарий над каждым ключом в самом файле объясняет его подробнее; ниже — основные ключи и значения по умолчанию.

## Язык

Мод говорит по-русски и по-английски. По умолчанию каждый игрок читает чат на языке своей игры (русский — для русского, украинского, белорусского и казахского клиента, английский — для остальных). Подсказки голограммы на экране всегда следуют языку клиента. Закрепить один язык для всего сервера:

```toml
[language]
language = "ru_ru"   # auto | en_us | ru_ru
```

| Значение | Что значит |
|---|---|
| `auto` | По умолчанию: каждый игрок читает на языке своего клиента |
| `en_us` | Английский для всех |
| `ru_ru` | Русский для всех |

## `[api]` — сервис генерации

| Ключ | По умолчанию | Что задаёт |
|---|---|---|
| `api_base_url` | `"https://ai.farmsteadminecraft.online"` | Адрес сервиса генерации |
| `bearer_token` | `""` | Токен сервера из [кабинета](https://farmsteadminecraft.online/cabinet/ai-builder) |
| `timeout_seconds` | `60` | Таймаут обычного запроса (`/aibuild get`), 10–300 с |
| `generate_timeout_seconds` | `600` | Таймаут генерации, 60–1800 с |

## `[links]`

| Ключ | По умолчанию | Что задаёт |
|---|---|---|
| `topup_url` | `"https://farmsteadminecraft.online/cabinet/wallet?currency=ai"` | Ссылка, которую мод показывает для пополнения. Пустое значение превращает команду в честный отказ вместо мёртвой ссылки |

## `[permissions]`

Уровни `*_level` для каждой подкоманды (`0` — все, `2` — операторы, `4` — консоль). Полная таблица — в разделе [«Права и LuckPerms»](../permissions/).

## `[chat]`

| Ключ | По умолчанию | Что задаёт |
|---|---|---|
| `announce_builds` | `true` | Сообщать всем игрокам онлайн, что чья-то постройка достроена, и как сделать свою |
| `announce_min_blocks` | `200` | Минимальный размер постройки для анонса, в блоках |
| `notify_updates` | `true` | Один раз при входе сообщать операторам о новой версии мода; в лог под `[hello]` это пишется всегда |

## `[region]` — выделение `/aibuild area`

| Ключ | По умолчанию | Что задаёт |
|---|---|---|
| `max_region_axis` | `100` | Самая длинная сторона области, в блоках (1–100 — предел сервиса) |
| `max_region_distance` | `192` | Как далеко от игрока можно ставить угол — защита от модифицированного клиента |

## `[placement]` — укладка блоков

| Ключ | По умолчанию | Что задаёт |
|---|---|---|
| `budget_ms` | `2` | Бюджет времени на укладку за тик сервера, 1–5 мс |
| `max_blocks` | `160000` | Максимум блоков в одной постройке (абсолютный предел 262144) |
| `default_strategy` | `"BOTTOM_UP"` | Порядок укладки: `BOTTOM_UP`, `TOP_DOWN`, `CENTER_OUT`, `LAYER_BY_LAYER` |

## `[preview]` — голограмма

| Ключ | По умолчанию | Что задаёт |
|---|---|---|
| `holo_max_blocks` | `20000` | Больше этого клиенту показывается только габаритная рамка |
| `aim_reach` | `128` | Как далеко можно отнести голограмму, в блоках |
| `drop_depth` | `160` | Если луч прицела никуда не попал — как глубоко искать землю вниз |
| `sky_distance` | `16` | Только для выделения: где ставится угол в воздухе |
| `ttl_seconds` | `300` | Сколько неподтверждённое предложение ждёт на сервере |

## `[animation]` — стройка на глазах

`enabled = true` включает послойную укладку с показом; `false` — постройка появляется целиком в конце. Остальные ключи секции (`blocks_per_tick`, `min_duration_ticks`, `max_duration_ticks`, `effects`, `ignition`, `sky_beam`, `snake_order`, `per_block_dissolve`, `landing_flash`, `hover_blocks`, `finale`, `build_sounds`) тонко настраивают темп и эффекты; описание каждого — в комментарии в файле.
