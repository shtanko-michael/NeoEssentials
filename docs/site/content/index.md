## Что это за сайт

Справочник по NeoEssentials — моду серверных «эссеншелов» для Minecraft 1.21.1 на NeoForge.
Здесь собрано всё, что нужно администратору и игроку: полный список команд, узлы прав, каждый
ключ конфигурации, разборы частых сценариев и список известных проблем.

Ключевое отличие от обычной вики: **таблицы команд, прав и конфигов не пишутся руками**. Они
извлекаются из исходников при каждой сборке сайта — из регистраций команд, из реестра прав и
из тех самых JSON-файлов, которые мод кладёт на сервер. Поэтому колонка «Право» показывает узел,
который мод проверяет на самом деле, а «По умолчанию» в конфиге — то значение, которое реально
приедет к вам в файле. Расходиться с кодом эти страницы не могут: если команду переименуют, а
сайт забудут обновить, сборка сайта просто не пройдёт.

Руками пишется другое — то, чего не выведешь из кода: примеры реальных задач, тонкие места на
стыках систем и известные проблемы с обходными путями.

проблемы, и в самом низу — подробное руководство из оригинальной документации проекта.

## Про версии

Сайт собирается из ветки `farmstead-monorepo-build` — форка NeoEssentials, который работает на
Minecraft **1.21.1** и NeoForge **21.1.179**. Оригинальный проект развивает ещё две линии, `26.1.x`
и `26.2.x`, под более новые версии игры; их команды и ключи конфигурации местами отличаются,
поэтому опираться на этот сайт стоит только для 1.21.1.
