Флаг устанавливается командой `/rg flag <id> <flag> <value>`. Булевы значения принимают `allow`, `deny`, `true` и `false`.

## Строительство и взаимодействие

| Флаг | Тип | По умолчанию | Что контролирует |
|---|---|---:|---|
| `build` | bool | `true`* | Резервное значение для строительных флагов, которые не заданы явно. |
| `block-break` | bool | `true` | Ломание блоков. |
| `block-place` | bool | `true` | Установку блоков, включая блок из предмета в руке. |
| `interact` | bool | `true` | Взаимодействие с блоками и сущностями, кроме PvP: двери, кнопки, стойки брони, атака сущностей и ПКМ по игроку. |
| `use` | bool | `true` | Использование не-контейнерных блоков. |
| `chest-access` | bool | `true` | Открытие обычных и модовых контейнеров. |
| `interact-allow` | set | `[]` | Разрешающие исключения по ID блока или сущности. |
| `interact-deny` | set | `[]` | Запрещающие исключения по ID блока или сущности. |
| `chest-access-allow` | set | `[]` | Разрешающие исключения для контейнеров. |
| `chest-access-deny` | set | `[]` | Запрещающие исключения для контейнеров. |

`*` В незаклеймленном регионе действует разрешающий default `build`. В регионе с владельцем или участником невыставленные строительные действия по умолчанию запрещены гостям.

Владелец и участник обходят строительные флаги независимо от их значения.

## Игроки и сущности

| Флаг | Тип | По умолчанию | Что контролирует |
|---|---|---:|---|
| `entry` | bool | `true` | Вход гостя в регион. При запрете игрок возвращается за границу. |
| `pvp` | bool | `true` | Урон игроку, который находится внутри региона. |
| `mob-damage` | bool | `true` | Урон игроку от моба, включая косвенный урон с источником-мобом. При `deny` игроки в регионе его не получают. |
| `invincibility` | bool | `false` | Полная неуязвимость игроков внутри региона. При `allow` / ВКЛ отменяется любой урон, в том числе PvP, от мобов, падения и окружения. |
| `passive-entity-damage` | bool | `true` | Урон пассивным существам. |
| `fall-damage` | bool | `true` | Урон игрока от падения. |
| `item-drop` | bool | `true` | Выбрасывание предметов игроком клавишей Q или переносом за пределы инвентаря. При `deny` предмет остаётся у игрока, а локализованное сообщение выводится в action bar. |
| `potion-splash` | bool | `true` | Взрыв бросаемых и lingering-зелий внутри региона. При `deny` зелье не срабатывает, даже если брошено снаружи. |
| `mob-spawning` | bool | `true` | Обычный спавн мобов, кроме `/summon`. |
| `mob-entry` | bool | `true` | Вход и нахождение мобов в регионе. |
| `mob-spawning-allow-only` | set | `[]` | Если список не пуст, разрешает спавн только перечисленных типов. |
| `mob-spawning-deny-only` | set | `[]` | Всегда запрещает спавн перечисленных типов. |

### PvP

`pvp deny` запрещает наносить урон любому игроку, находящемуся в регионе. Правило симметрично: владелец, участник и гость не могут бить друг друга. Проверяется позиция жертвы, поэтому удар снаружи внутрь также блокируется.

Запрет охватывает прямую атаку и косвенный урон, у которого источником является игрок, например стрелу. Единственный обход — `regionguard.bypass.pvp`; OP уровня 2 также считается администратором с обходом.

### Безопасная зона

`mob-damage deny` создаёт PVE-безопасную зону: игроки внутри не получают урон, источником которого является моб. `invincibility allow` (ВКЛ) сильнее — полностью отменяет любой урон игроку в регионе, без исключений для владельцев, участников или OP. Флаг не делает игрока невидимым и не выдаёт эффект невидимости.

`item-drop deny` отменяет выбрасывание предмета, возвращает уже извлечённый стек в инвентарь выжившего игрока и показывает action-bar сообщение `protection.item_drop_deny`. `potion-splash deny` проверяется в точке попадания: нельзя забросить зелье извне в защищённую зону, а появление lingering-облака там также отменяется.

Пример безопасной зоны:

```text
/rg flag spawn mob-damage deny
/rg flag spawn item-drop deny
/rg flag spawn potion-splash deny
/rg flag spawn invincibility allow
```

## Мир и эффекты

| Флаг | Тип | По умолчанию | Что контролирует |
|---|---|---:|---|
| `fire-spread` | bool | `true` | Появление и распространение огня. |
| `tnt` | bool | `true` | Взрыв TNT. |
| `creeper-explosion` | bool | `true` | Взрыв крипера. |
| `other-explosion` | bool | `true` | Остальные взрывы. |
| `weather` | string | `server` | Персональную погоду: `server`, `sun`/`clear`, `rain`, `storm`/`thunder`. |
| `thunder` | bool | `true` | Молнии и грозу. |
| `beacon` | set | `[]` | Эффекты формата `эффект:уровень`, поддерживаемые внутри региона. |

Погода отправляется игроку пакетами и не меняет реальную погоду мира. Эффекты маяка обновляются раз в секунду.

## Сообщения региона

| Флаг | Тип | По умолчанию | Что контролирует |
|---|---|---:|---|
| `greeting` | string | `""` | Сообщение при входе, отображается в action bar над хотбаром. |
| `farewell` | string | `""` | Сообщение при выходе, отображается в action bar над хотбаром. |
| `deny-message` | string | `""` | Сообщение при запрещённом действии. |

Строки поддерживают цветовые коды с `&`. Пустой `deny-message` использует локализованное сообщение мода.

Например:

```text
/rg flag spawn greeting &aДобро пожаловать на спавн!
/rg flag spawn farewell &eДо встречи!
```

## Флаги нового привата

При `/rg define` мод явно записывает два набора из серверного конфига. По умолчанию запрещены `build`, `block-break`, `block-place`, `interact`, `chest-access`, `tnt` и `invincibility`; остальные булевы флаги, включая `mob-damage`, `item-drop` и `potion-splash`, явно разрешены.

`interact deny` защищает от гостей двери, кнопки и взаимодействия с сущностями. Владельцы, участники и OP уровня 2 обходят этот строительный флаг. Для конкретного региона значение можно изменить командой `/rg flag <id> interact allow|deny`.
