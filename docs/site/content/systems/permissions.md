## Явная выдача (поставка Farmstead)

В `config.json` стоит `permissions.requireExplicitGrant: true`. Игрок получает команду только
после явного гранта узла в LuckPerms (или во внутреннем менеджере, если внешний адаптер
выключен). Значение `defaultValue: true` в `PermissionRegistry` **не** открывает узел само.

OP уровня 2+ по-прежнему проходит, пока `opsBypassPermissions: true`. Чтобы операторы жили
по тем же правилам, что игроки, поставьте `opsBypassPermissions: false`.

Старое поведение «почти все игровые команды доступны всем, пока их не запретили» возвращается
только так: `requireExplicitGrant: false`.

Раздел «Подробное руководство» ниже — исходный текст апстрима. Там ещё описаны тихие гранты
по `defaultValue`. Для этой сборки опирайтесь на цепочку в тонких местах этой страницы и на
[Быстрый старт](../../quickstart/index.html).

Проверить живой результат: `/permissions debug <ник>` — в выводе есть `requireExplicitGrant`.
