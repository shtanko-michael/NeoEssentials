Серверный мод (`farmstead_chunkbreeding`) для **NeoForge 21.1.230+ / Minecraft 1.21.1**: игрокам устанавливать его не нужно. Он отменяет появление нового детёныша, когда в области фермы уже достигнут лимит животных. Существующих животных мод не удаляет.

## Область подсчёта: регион или чанк

По умолчанию `scope = "region"`. Если на сервере стоит **[Farmstead Claims](../../claims/)** и родители находятся внутри обычного региона, мод считает животных во всём этом регионе, даже если ферма пересекает несколько чанков. Разместить один загон по обе стороны границы чанка для обхода лимита не получится.

Два соседних региона независимы: животные из региона игрока A не расходуют лимит региона игрока B. Глобальный технический регион `__global__` фермой не считается. Если животные стоят вне региона либо Farmstead Claims не установлен (зависимость необязательная), мод автоматически использует один чанк 16×16 блоков на всю высоту мира.

Регионы берутся только из Farmstead Claims: исходный RegionGuard этот мод не опрашивает — с ним действует правило чанка.

## Что ограничивается

- **Размножение.** Новый детёныш не появляется, если в области уже `лимит` животных или больше. Игрок, который кормил животных, видит над хотбаром: `Лимит животных в регионе 'cows' уже достигнут: 15/15.`
- **Яйца призыва** (`spawnEggsRespectLimit = true`). Яйцо мирного моба, использованное на блоке или на животном, не создаст животное сверх лимита. Это касается и спавнеров, настроенных яйцом: лишнее животное из такого спавнера не появится. Яйца враждебных мобов и раздатчики не затрагиваются.
- В счётчик входят взрослые и детёныши всех мобов класса `Animal`.

## Команды оператора

Все команды требуют уровень прав **2** (оператор). Значения, установленные командами, сразу применяются и записываются в конфиг — переживают рестарт.

| Команда | Что делает |
|---|---|
| `/chunkbreedlimit get` | Показывает лимит и активную область подсчёта |
| `/chunkbreedlimit set <0-10000>` | Сразу устанавливает общий лимит и сохраняет его |
| `/chunkbreedlimit scope region` | Считать по региону Farmstead Claims; вне региона — по чанку |
| `/chunkbreedlimit scope chunk` | Всегда считать только в одном чанке |
| `/chunkbreedlimit count <животное>` | Число животных этого типа и лимит в области выбранного животного |

Пример: `/chunkbreedlimit count @e[type=minecraft:cow,limit=1,sort=nearest]` — сколько коров в области ближайшей коровы и какой для них лимит. Если у вида нет своего предела в `entityLimits`, считаются все животные области.

## Конфиг

После первого запуска сервера появляется `config/farmstead-chunk-breeding.toml`:

```toml
enabled = true
spawnEggsRespectLimit = true
operatorsBypassSpawnEggLimit = true
scope = "region"
maxAnimalsPerChunk = 24
entityLimits = ["minecraft:cow=12", "minecraft:chicken=32"]
```

| Ключ | По умолчанию | Что задаёт |
|---|---|---|
| `enabled` | `true` | Включает лимиты |
| `spawnEggsRespectLimit` | `true` | Яйца призыва мирных мобов и спавнеры с яйцом подчиняются тому же лимиту |
| `operatorsBypassSpawnEggLimit` | `true` | Операторы (уровень 2) обходят лимит для яиц; `false` — лимит и для них |
| `scope` | `"region"` | `region` — регион Farmstead Claims, вне него чанк; `chunk` — всегда чанк |
| `maxAnimalsPerChunk` | `24` | Общий предел животных в области (0–10000; `0` запрещает любое размножение) |
| `entityLimits` | `[]` | Отдельные пределы для видов в формате `идентификатор_моба=число` |

Запись из `entityLimits` заменяет общий предел для своего вида: при `maxAnimalsPerChunk = 15` и `minecraft:cow=12` коров будет не больше двенадцати, а считаются при этом только коровы. Неверные записи игнорируются.

При ручном редактировании TOML перезапустите сервер или перезагрузите конфиг. Для обычной работы удобнее команды: они применяют и сохраняют значение сразу.

## Как подготовить независимые фермы

1. Выделите территорию первой фермы обычной командой Farmstead Claims, например `/rg define cows` после выбора двух углов.
2. Убедитесь, что загон целиком находится внутри этого региона: `/rg info cows`.
3. Оставьте режим `region` и задайте лимит: `/chunkbreedlimit set 15`.
4. Для следующей фермы создайте отдельный, не пересекающийся регион. Её лимит не будет зависеть от первой.

Если регионы не используются, включите `/chunkbreedlimit scope chunk`; в этом режиме игрокам стоит строить загон целиком в одном чанке (границы показывает `F3 + G`).
